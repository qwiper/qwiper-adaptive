# Security

The built-in probe reads aggregate Android resource characteristics locally.
It does not collect device identifiers, transmit data, persist observations,
or request runtime permissions. Hosts are responsible for any telemetry they
add around the library. Do not log custom reader errors containing private data.

For a suspected vulnerability, use the repository's [private vulnerability
reporting form](https://github.com/qwiper/qwiper-adaptive/security/advisories/new).
Private vulnerability reporting is enabled. Reports are handled by the repository
maintainers; the maintainer contact is Issoufa ABDOU OUSMANE through that form.
Do not include exploit details, credentials or user data in public issues.

No response-time commitment or independently audited security status is claimed
by this package.
